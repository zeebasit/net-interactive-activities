Module 4 Activity 1

Practise the number systems used in networking

You will complete 12 questions in a controlled sequence. The values change every time you start a new set, but the activity always progresses from binary foundations to hexadecimal conversion.

1

Build and read binary

Use the place values 128, 64, 32, 16, 8, 4, 2 and 1 to move between decimal and 8-bit binary.

2

Work with hexadecimal

Split a byte into two 4-bit nibbles and convert each nibble to one hexadecimal digit.

3

Connect the systems

Complete mixed conversions using binary as the bridge between decimal and hexadecimal.

Practice mode: You have two attempts for each question. After the first incorrect attempt, you receive a targeted hint. After the second, the worked solution is shown.
