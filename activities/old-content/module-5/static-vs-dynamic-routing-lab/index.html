Static vs Dynamic Routing Lab

Compare how routes are learned, see routers exchange reachability information, and investigate how static and dynamic routing respond when the network changes.

Same destination, different method

How does the route enter the table?

Both methods can deliver a packet to the same destination. The difference begins with how the router learns the route and who must respond when the topology changes.

Static routing

Administrator controlled
  • The administrator identifies the destination and path.
  • The route is entered manually on the required routers.
  • The router does not exchange this route automatically.
  • A backup path must be configured or added manually.

Dynamic routing

Router communication
  • Routers start with directly connected networks.
  • They exchange reachability information with neighbours.
  • They compare available paths using protocol rules.
  • They can adapt when learned information changes.

Convergence

After a topology change, routers exchange updated information and recalculate their preferred routes. The network is converged when participating routers have reached a consistent, stable understanding.
