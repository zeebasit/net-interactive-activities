Decision guide

First identify the destination IP address carried inside the packet. The router keeps this address unchanged while it forwards the packet.

Remember: the next hop is the neighbouring router that receives the packet next—not the final remote host.

Route construction

ip route <destination-network> <mask> <next-hop>

Destination: the remote network—not a host inside it.

Next hop: the adjacent router interface reachable from R1.

Return path: traffic is bidirectional, but a static route is not. The remote router also needs a route back to LAN A.

Longest-prefix matching

When is the default route selected?

The default route is a catch-all. It is used only when the routing table contains no more specific match for the destination.

Which entry will the router use?

Choose the route with the longest matching prefix. A /24 is more specific than /16, and both are more specific than /0.

Configuration retains both commands during normal operation and failure.

Installed routing-table entry

Key distinction: configured does not always mean installed. The floating route stays in the configuration but normally remains absent from the routing table.
