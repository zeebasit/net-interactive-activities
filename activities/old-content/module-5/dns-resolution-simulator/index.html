Inspect a DNS query and response

DNS messages contain a header and sections for questions and resource records. Select each area to understand the information used in this example.

Header field

Transaction ID

A 16-bit identifier selected by the requester. The response repeats it so the PC can match the answer to the correct query.

Query ID: 0x4A3C
Response ID: 0x4A3C
Transport in this example: The PC sends a standard DNS query using UDP to destination port 53. DNS can also use TCP, so UDP should not be treated as the only possible transport.
