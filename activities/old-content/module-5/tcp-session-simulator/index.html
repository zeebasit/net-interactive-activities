Inspect the fields TCP uses

Select any header field or control flag to see its purpose. The simulation will focus on ports, sequence numbers, acknowledgment numbers and the SYN, ACK and FIN flags.

16 bits

Source Port

Identifies the sending application process. A client normally chooses a temporary source port, such as 49152.

  • MSS: maximum TCP payload the sender accepts in one segment.
  • Window Scale: permits receive windows larger than 65,535 bytes.
  • SACK Permitted: indicates support for selective acknowledgments.
  • Timestamps: supports improved timing and sequence-number protection.
Important: TCP options are variable-length header extensions. They are different from the one-bit control flags such as SYN, ACK and FIN.
