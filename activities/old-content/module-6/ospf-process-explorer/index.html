Broadcast multi-access network

Elect the DR and BDR

On a shared Ethernet segment, OSPF reduces unnecessary adjacency and flooding complexity by electing a Designated Router and Backup Designated Router.

Election inputs

RouterPriorityRouter ID

Election result

Highest interface priority wins. Router ID breaks a priority tie. Priority 0 is ineligible.
Priority 0: a router whose OSPF interface priority is 0 does not participate as a candidate in the DR/BDR election. It remains a DROTHER router.
Scope: DR/BDR elections apply on broadcast multi-access segments. A point-to-point OSPF link does not need a DR or BDR.
