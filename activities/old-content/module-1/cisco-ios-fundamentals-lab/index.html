Quick glossary
CLI
Command-Line Interface.
Prompt
The text showing the device name and current IOS mode.
EXEC
A mode used to execute monitoring or management commands.
RAM
Temporary memory holding the active running configuration.
NVRAM
Non-volatile storage traditionally used for the startup configuration.
